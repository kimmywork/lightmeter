# Digital Light Meter

A Progressive Web App that serves as a digital light meter for photographers. Access it at [meter.kimmy.fun](https://meter.kimmy.fun).

## Features

- 📱 Progressive Web App (PWA) with offline support
- 📷 Professional light metering for photographers (Only verified with iPhone 15 Pro Max.)
- 🌐 Mobile-optimized interface
- 🔄 Automatic updates notification
- 💻 Cross-platform compatibility

## Development

This project is built with React and uses modern web technologies.

### Prerequisites

- Node.js (Latest LTS version recommended)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install
```
### Available Scripts

- `npm start` - Runs the app in development mode at http://localhost:3000
- `npm test` - Launches the test runner
- `npm run build` - Builds the app for production
- `npm run eject` - Ejects from Create React App (one-way operation)

### Technology Stack

- React
- Material-UI
- Service Workers for PWA
- Styled Components
- Web Vitals
